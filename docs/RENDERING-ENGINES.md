# Rendering & component engines

| Surface | Engine | Purpose |
|---|---|---|
| Home/Academy | Next.js static | SEO + stable marketing content |
| Catalog | Next.js ISR | fast catalog with revalidation |
| Dashboard | Next.js dynamic SSR | current operational state |
| API | Route handlers | typed JSON/integration surfaces |
| iOS | SwiftUI | native mobile client |
| PDF/print | server artifact pipeline | catalogs, receipts, learning publications |
| Simulation | scripted/provider adapter | deterministic fallback + optional AI |

Shared packages prevent storefront, LMS and mobile metadata from drifting independently.
